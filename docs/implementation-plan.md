# Implementation plan

## Blocks

1. Project structure, tooling and documentation.
2. Domain model and SOLID contracts.
3. FastAPI generation API and job lifecycle.
4. vLLM gateway for text and vision models.
5. Mock video worker for GPU-free end-to-end tests.
6. DeepAgents orchestrator with specialized subagents.
7. Agent skills for prompting, routing and quality review.
8. React/Vite Claude-style interface.
9. LTX-Video adapter, then Wan I2V adapter.
10. Persistence, Docker profiles, observability and security.

Every block must be tested before commit.
